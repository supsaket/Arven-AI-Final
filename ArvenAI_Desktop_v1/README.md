# ARVEN AI — Desktop Application

A PySide6 desktop application shell designed to sit on top of the existing Arven AI codebase.

Included:
- Home dashboard
- Arven animated visual/orb
- AI Chat page with FastAPI integration
- Local task manager
- SQLite memory viewer
- Security Center dashboard
- Settings
- Windows packaging instructions

The UI is intentionally separated from the existing Arven core so the existing `core/`, memory, voice, agent and FastAPI code can be integrated without replacing it.
